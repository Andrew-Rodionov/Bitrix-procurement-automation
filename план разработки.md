# План разработки системы автоматизации закупок

Разработка проходит последовательно: локальное веб-приложение → переписка с поставщиками → поиск поставщиков → внедрение в коробочный Битрикс24.

- [x] Создать локальный прототип приложения, доступный через браузер.
- [x] Подключить языковую модель через API.
- [x] Реализовать передачу текста на обработку.
- [x] Получать и отображать краткое резюме текста.

**Результат:** приложение открывается в браузере, принимает текст и формирует резюме с помощью ИИ.

## 2. Обработка закупочной заявки

- [ ] Добавить форму заявки: товар, количество, характеристики, бюджет, сроки и место поставки.
- [ ] Реализовать проверку обязательных полей.
- [ ] Научить ИИ выявлять недостающие и неоднозначные требования.
- [ ] Формировать уточняющие вопросы инициатору.
- [ ] Подключить базу данных для хранения заявок и результатов обработки.
- [ ] Добавить статусы заявки и историю изменений.

**Результат:** система получает понятную и сохраненную заявку, на основании которой можно запрашивать предложения.

## 3. Подключение электронной почты

- [ ] Подключить тестовый почтовый ящик.
- [ ] Реализовать отправку писем из приложения.
- [ ] Реализовать получение ответов.
- [ ] Сохранять входящие и исходящие сообщения.

- [ ] Исключить повторную обработку одного сообщения.

**Результат:** приложение отправляет запрос поставщику и получает его ответ в рамках одной переписки.

## 4. Двусторонняя переписка с помощью ИИ

- [ ] Добавить ручной ввод списка поставщиков и их контактов.
- [ ] Формировать запрос коммерческого предложения по заявке.
- [ ] Сначала проверять подготовленные ИИ письма перед отправкой.
- [ ] Извлекать из ответов цену, наличие, сроки, доставку, оплату и гарантию.
- [ ] Определять, каких сведений недостаточно.
- [ ] Формировать и отправлять уточняющие вопросы.
- [ ] Обрабатывать последующие ответы с учетом истории диалога.
- [ ] Ограничить число уточнений и напоминаний.
- [ ] Установить срок завершения переписки.
- [ ] Передавать спорные случаи человеку.
- [ ] Настроить фоновую обработку, чтобы переписка продолжалась при закрытом браузере.
- [ ] Обрабатывать сбои почты и API без потери состояния и бесконтрольных повторных отправок.

**Результат:** ИИ ведет ограниченный правилами диалог с заданными поставщиками и собирает условия закупки. Отправку и допустимые действия контролирует приложение.

- [ ] Прикреплять к извлеченным значениям исходное письмо или цитату.
- [ ] Различать цену за единицу, упаковку и всю партию.
- [ ] Учитывать доставку и известные дополнительные расходы.
- [ ] Проверять соответствие обязательным требованиям.
- [ ] Отмечать отсутствующие сведения, аналоги и частичные поставки.

- [ ] Формировать резюме с объяснением результатов.
- [ ] Добавить подтверждение выбора поставщика человеком.
