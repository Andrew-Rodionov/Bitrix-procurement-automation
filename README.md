# Bitrix-procurement-automation

на момент 08.11.2026 программа резюмирует текст и выдает основную важную информацию. почта не задействована, реализуется на вебке.
API используется от сбера.

<img width="1118" height="707" alt="image" src="https://github.com/user-attachments/assets/2565fc5b-3ae9-4610-9452-d0d16363e2d7" />

Почтовый интерфейс добавлен: ручная проверка последних 20 входящих, выбор письма для анализа, отправка текста сотрудника нескольким адресатам отдельными письмами. Для подключения ящика @citology.ru введите адрес и пароль в форме входа на странице. Параметры mail.olimp5.ru (IMAP 993, SMTP 465, TLS) уже подготовлены. Полная инструкция: openai-demo/README.md. Вложения пока не анализируются.
